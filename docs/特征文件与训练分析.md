# 特征文件分析：模型输入 / 标注输出 / 训练脚本特征

> 分析日期：2026-09-05 · 统计脚本：`scripts/analyze_datasets.py`（可重跑复现）
>
> 范围：两个已购 YOLO 数据集（受电弓目标检测、轨道异物检测 RailFOD23），服务 `internal.panto.*` 与 `internal.lineside.fod` 能力。

## 1. 受电弓目标检测数据集（`高体受电弓设备目标检测数据集 YOLO格式/`）

来源：Roboflow Universe `pantograph-9bhnb/pantograph-qxcoc` v6，**CC BY 4.0**。

### 1.1 模型输入（图像）

| 项 | 值 |
| --- | --- |
| 图像尺寸 | 统一 **640×640**（Roboflow 导出时已预缩放，训练无需再裁剪） |
| 数量 | train 2,275 / valid 265 / test 136（共 2,676） |
| 无标注图 | 0（每张图都有对应标签） |
| 内容 | 轨旁/车载视角的受电弓，含接触点、支柱、导电条带 |

### 1.2 模型输出（YOLO 标签特征）

标签格式：`class_id cx cy w h`（归一化中心点+宽高），每图一行一个目标。

| 统计项 | train | valid | test |
| --- | --- | --- | --- |
| 实例总数 | 5,203 | 606 | 312 |
| 每图目标数 min/avg/max | 0 / 2.29 / 5 | 1 / 2.29 / 4 | 1 / 2.29 / 3 |
| **类别分布** | contact_point 2,257 · strip 2,276 · mast 670 | 258 / 265 / 83 | 134 / 136 / 42 |
| 面积分档 | small(<1%) 2,384 · medium 2,819 · large 0 | — | — |
| bbox 归一化宽高极值 | 最大 (0.203, 0.885)（细长竖条——侧视支柱/条带），最小 (0.0086, 0.0117)（≈0.01% 面积的接触点小目标） | | |

**特征结论**：
- **contact_point 与 strip 数量≈1:1**——每张图一条滑板配一个接触点，符合"弓网接触"成像规律；mast 较少（约 1/3 图含支柱）。
- **无 large 目标、以 small/medium 为主**，且 strip 框呈细长形（宽 0.2、高 0.885 的竖长框），对模型的细长目标回归能力有要求。
- 最小目标仅 ~0.01% 图面积，是 mAP 主要难点（contact_point 检出率决定接触点定位精度）。

### 1.3 训练脚本特征（`scripts/train_yolo26.py`）

| 项 | 配置 | 说明 |
| --- | --- | --- |
| 模型 | **YOLO26n**（ultralytics 8.4.140，cfg/models/26/yolo26.yaml） | 端到端 NMS-free 新架构；预训练权重因 GitHub 不可达自动回退从零训练 |
| 输入 | imgsz=640（与数据集原生尺寸一致，零缩放损失） | |
| 训练 | batch=16 · epochs=30 · device=0（RTX 3080）· workers=4 · patience=50 | 两数据集串行，全程约 40 分钟 |
| 数据路径 | 训练脚本自动把 Roboflow 的 `../train/images` 相对路径改写为绝对路径（`data_fixed.yaml`） | 避免相对路径解析错误 |
| 增广 | ultralytics 默认（mosaic、HSV 抖动、水平翻转等，close_mosaic=10） | |
| 产出 | `runs/panto_y26n/weights/best.pt` → 已拷贝至 `railmind/capabilities/panto/weights/` | results.csv / confusion_matrix.png 齐全 |

**训练结果**：mAP50 **0.768**、mAP50-95 0.539、P 0.751 / R 0.715（30ep 从零训练；商家宣传的 0.921 为 v8s+100ep 配置，参赛材料如实标注两者差异）。

**能力侧用途**：`internal.panto.wear_vlm` 用该模型检测 strip → 裁剪滑板区域（带 15% 边距）→ 交 LLM 视觉评估磨耗等级，解决整图中小目标看不清的问题。

## 2. 轨道异物检测数据集（`RailFOD23.v1i.yolov8/`）

来源：Roboflow Universe `adeemvlm/railfod23` v1，**CC BY 4.0**。

### 2.1 模型输入

| 项 | 值 |
| --- | --- |
| 图像尺寸 | 统一 640×640 |
| 数量 | train 1,779 / valid 508 / test 254（共 2,541） |
| 内容 | 轨道/线路侧异物：鸟巢、漂浮物、气球、塑料袋（夜景与白天混合） |

### 2.2 模型输出（YOLO 标签特征）

| 统计项 | train | valid | test |
| --- | --- | --- | --- |
| 实例总数 | 4,794 | 1,371 | 750 |
| 每图目标数 min/avg/max | 1 / 2.69 / **32** | 1 / 2.70 / 24 | 1 / 2.95 / 22 |
| **类别分布** | piaofuwu 1,754 · qiqiu 1,327 · niaocao 1,145 · suliaodai 568 | 491/372/382/126 | 268/250/167/65 |
| 面积分档 | **small 3,188（66%）** · medium 1,405 · large 201 | — | — |
| bbox 归一化宽高极值 | 最大 (0.903, 0.947)（近距大目标），最小 (0.0258, 0.0258) | | |

**特征结论**：
- **66% 为小目标**（<1% 图面积），且单图最多 32 个目标（鸟群/漂浮物群聚场景）——小目标+密集是主要挑战。
- **类别不平衡约 3:1**（漂浮物 1,754 vs 塑料袋 568），与实际线路异物先验分布一致。
- 训练脚本与受电弓完全一致（同 `scripts/train_yolo26.py`，仅 data/name 不同）。

**训练结果**：mAP50 **0.699**、mAP50-95 0.479（YOLO26n 30ep 从零；短训+小目标为主导致，继续加 epoch 或用 v8s 权重蒸馏可提升）。

**能力侧用途**：`internal.lineside.fod` —— 图像输入 → 四类异物检测 → 面积占比 >5% 判 HIGH、否则 WARNING → 证据图存档，供 LineSide-Agent 综合处置。

## 3. 与平台能力的对应关系

```text
受电弓图像 ──► panto 检测层(YOLO26n) ──► strip 裁剪 ──► wear_vlm(LLM 磨耗分级) ──┐
弓上电压/电流波形 ──► arc_signal(可解释信号链, Mendeley 真实数据) ──────────────┼──► Panto-Agent ──► Chief-Agent
巡检/影像点图片 ──► lineside.fod(YOLO26n 四类异物) ──────────────────────────┘        │
复合材料 Lamb 波 ──► shm.impact_locator(EnhancedLambWaveNet) ──► SHM-Agent ──────────┤
车底检查门照片 ──► underbody.door_pose(YOLOv8-pose) ──► Underbody-Agent ─────────────┘
                                                        ▼
                                    确定性风险引擎 + RAG 演示规程 + 工单草稿（人工确认）
```
